# Data Visualization

Bagmaster provides powerful visualization capabilities for analyzing your bag data.

## Visualization Types

### 3D Visualization

View point clouds, trajectories, and robot models in 3D using the integrated Lichtblick player.

### Time-Series Plots

Plot numeric data over time:
- Sensor readings
- Robot states
- Custom metrics

### Image Viewer

Display camera feeds and image topics with synchronized playback.
