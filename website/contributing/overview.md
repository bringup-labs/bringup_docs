# Contributing to Bagmaster

Thank you for your interest in contributing to Bagmaster! This guide will help you get started.

## Ways to Contribute

There are many ways to contribute to Bagmaster:

- 🐛 **Report bugs** - Help us identify and fix issues
- 💡 **Suggest features** - Share ideas for new functionality
- 📝 **Improve documentation** - Help others understand and use Bagmaster
- 💻 **Write code** - Implement new features or fix bugs
- 🎨 **Improve UI/UX** - Enhance the user experience
- 🧪 **Write tests** - Improve code quality and coverage

## Getting Started

### 1. Fork the Repository

Fork the [Bagmaster repository](https://github.com/rahulkatiyar19955/bagmaster) on GitHub.

### 2. Set Up Development Environment

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/bagmaster.git
cd bagmaster

# Add upstream remote
git remote add upstream https://github.com/rahulkatiyar19955/bagmaster.git

# Install dependencies
docker-compose -f docker-compose.dev.yml up -d
```

### 3. Create a Branch

```bash
git checkout -b feature/my-new-feature
```

### 4. Make Changes

Follow our [coding standards](./coding-standards) and [testing guidelines](./testing).

### 5. Submit a Pull Request

1. Push your changes to your fork
2. Open a pull request on GitHub
3. Describe your changes clearly
4. Link any related issues
