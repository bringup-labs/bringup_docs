# Bagmaster Documentation — Website

The Docusaurus website package for Bagmaster documentation. This is a workspace package within the `bagmaster_docs` monorepo.

See the [root README](../README.md) for setup instructions, Docker usage, and project structure.

## Quick Start

From the monorepo root (`bagmaster_docs/`):

```bash
pnpm install
pnpm start
```

Or directly from this directory:

```bash
pnpm install
pnpm start
```
