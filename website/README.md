# Bringup Documentation — Website

The Docusaurus website package for Bringup documentation. This is a workspace package within the `bringup_docs` monorepo.

Note that the site's content is **not** in this directory — it lives in `../docs/`. This package holds the Docusaurus config, theme, and custom components.

See the [root README](../README.md) for setup instructions, Docker usage, and project structure.

## Quick Start

From the monorepo root (`bringup_docs/`):

```bash
pnpm install
pnpm start
```

Or directly from this directory:

```bash
pnpm install
pnpm start
```
